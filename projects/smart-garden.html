Self-Watering Smart Garden

A soil-sensing irrigation box that waters itself and logs data to a web dashboard.

Timeframe
April 2025 – June 2025
Tools used
ESP32, capacitive soil sensors, water pump, plywood, Node.js dashboard
Category
IoT, Woodworking, Web Dev

The problem

My family's herb garden kept dying whenever we went on vacation, so I built a planter box that waters itself and lets us check soil moisture remotely.

How it works

A capacitive soil moisture sensor reports readings to an ESP32 every 15 minutes. When moisture drops below a threshold, the ESP32 triggers a small water pump for a timed burst and logs the event to a simple Node.js dashboard over Wi-Fi.

Build process

  • Built and sealed the plywood planter box with a separate reservoir compartment.
  • Wired the sensor, pump, and relay to the ESP32 and wrote the control firmware.
  • Built a small Node.js + SQLite backend to log and chart moisture over time.
  • Ran a 3-week trial and tuned the watering threshold based on the plant's response.

Results

The herbs survived a two-week vacation for the first time, and the moisture logs made it easy to see when the watering threshold needed adjusting for different plants.

What I'd do differently

Add a second sensor at a different depth — the surface sensor sometimes read "dry" right after watering even though the root zone was still saturated.
