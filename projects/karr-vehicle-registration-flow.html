KARR Vehicle Registration Flow

Built a mobile registration and vehicle onboarding flow using React Native, with API integration for KARR's vehicle reporting platform.

Timeframe
June 2025 – August 2025
Tools used
React Native, Expo, TypeScript, Expo Router, React Native Safe Area Context, REST APIs
Category
Mobile Development, API Integration
Context
Internship project at KARR

The problem

KARR was developing a mobile application that would allow users to report and manage their vehicles online. Users needed a straightforward way to create an account, enter their information, and register a vehicle before accessing the broader platform. I was responsible for developing the frontend registration experience and working on connecting the application to external vehicle data through API calls.

How it works

I built the Login, Signup, and Vehicle Registration screens using React Native and connected them into a multi-screen flow with Expo Router. The interface collects user and vehicle information, validates required inputs, and guides users through each stage of registration.

I also worked with API requests designed to connect vehicle registration information entered by the user with external vehicle data. This involved handling asynchronous requests, processing API responses, and connecting the mobile frontend with external services.

Process

  • Reviewed KARR's requirements and identified the screens and information needed for the registration flow.
  • Built the Login, Signup, and Vehicle Registration interfaces using React Native and TypeScript.
  • Connected the screens using Expo Router to create a continuous onboarding flow.
  • Added form handling and input validation for user and vehicle information.
  • Worked with API calls for retrieving vehicle-related information from registration data.
  • Tested the application in Expo and debugged frontend, navigation, and integration issues.
  • Explored the project's backend and authentication architecture while working on the integration.

Results

Completed the core frontend registration flow for KARR's mobile application, providing a foundation for its user onboarding experience and future connection to the broader vehicle-reporting platform. The project gave me hands-on experience developing within a startup codebase and strengthened my skills in React Native, TypeScript, mobile navigation, API integration, and debugging.

What I'd do differently

I would continue developing the backend integration so vehicle information could be retrieved and verified directly from a user's registration number. I would also improve loading and error states around API requests, strengthen form validation, add automated testing, and further separate UI and API logic into reusable components and services to make the application easier to maintain and expand.
