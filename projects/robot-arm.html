3-DOF Robotic Arm

A servo-actuated arm controlled by inverse kinematics running on a Raspberry Pi.

Timeframe
September 2025 – November 2025
Tools used
Raspberry Pi, MG996R servos, Python, Fusion 360, laser-cut acrylic
Category
Robotics, Software

The problem

I wanted to understand how industrial pick-and-place arms calculate joint angles from a target position, so I built a small-scale version I could program and test by hand.

How it works

Three servos form shoulder, elbow, and wrist joints. A Python script running on a Raspberry Pi solves the inverse kinematics for a given (x, y, z) target and converts the result into servo angles over a serial connection.

Build process

  • Laser-cut and assembled the acrylic arm segments and joints.
  • Derived the inverse kinematics equations for the 3-link arm on paper first.
  • Implemented and unit-tested the IK solver in Python before wiring any hardware.
  • Calibrated servo angle offsets to correct for physical assembly slop.

Results

The arm can reliably pick up a small object and move it to a target coordinate within about 1cm of accuracy across its working envelope.

What I'd do differently

Upgrade from hobby servos to ones with position feedback — the biggest source of error is servos not quite reaching the commanded angle under load.
